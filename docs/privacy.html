Kurzfassung: Die Erweiterung läuft vollständig in Ihrem Browser. Sie sendet keine Daten an den Entwickler oder an Dritte. Sie kommuniziert ausschließlich mit chatgpt.com, um Ihre Chat-Liste anzuzeigen und die von Ihnen ausdrücklich ausgelösten Aktionen (Archivieren, Wiederherstellen, Löschen) auszuführen.

„Bulk Manager für ChatGPT“ ist ein privates, nicht-kommerzielles Open-Source-Projekt. Kontakt: chrome@nspm.ovh. Quellcode: github.com/aemjay/bulk-manager-for-chatgpt.

Die Erweiterung ist kein Produkt von OpenAI und steht in keiner Verbindung zu OpenAI. ChatGPT ist eine Marke von OpenAI.

3. Empfänger

Daten werden ausschließlich an chatgpt.com (OpenAI) übertragen, weil die Aktionen dort ausgeführt werden. Schreibende Anfragen (Archivieren, Wiederherstellen, Löschen) erfolgen nur auf Ihren ausdrücklichen Klick. Für die Verarbeitung durch OpenAI gilt die Datenschutzerklärung von OpenAI.

Es gibt keine Übermittlung an den Entwickler oder an sonstige Dritte, keinen Verkauf von Daten, keine Analyse-, Tracking- oder Werbedienste und keinen nachgeladenen Code. Der Entwickler betreibt keine Server für diese Erweiterung und erhält keinerlei personenbezogene Daten.

4. Berechtigungen

  • Zugriff auf chatgpt.com: Panel auf der Seite anzeigen, Chat-Liste abrufen, Aktionen ausführen. Andere Websites werden nicht angesprochen.
  • storage: Speichern der einen Einstellung (N) auf Ihrem Gerät.
  • scripting: Nachladen des mitgelieferten Panels in chatgpt.com-Tabs, die schon vor der Installation geöffnet waren.

Privacy Policy

Last updated: October 22, 2026

Summary: The extension runs entirely in your browser. It sends no data to the developer or any third party. It communicates only with chatgpt.com to display your conversation list and to perform the actions you explicitly trigger (archive, restore, delete).

1. Provider and contact

“Bulk Manager für ChatGPT” is a private, non-commercial open-source project. Contact: chrome@nspm.ovh. Source code: github.com/aemjay/bulk-manager-for-chatgpt. Not affiliated with OpenAI. ChatGPT is a trademark of OpenAI.

2. Data processed

  • chatgpt.com session access token (from chatgpt.com/api/auth/session): authenticates requests to chatgpt.com on your behalf. Kept in tab memory only, until the tab is reloaded or closed.
  • User and account identifier from the same session response: ensures that the list, the selection and all actions belong to the same account; on an account or session change everything loaded is discarded. Memory only.
  • chatgpt.com device identifier (cookie oai-did): forwarded as a header to chatgpt.com, as the site itself does. Memory only.
  • Conversation metadata (ID, title, last-updated time, pinned/project flags): display, search and selection in the panel. Memory only.
  • One setting (the number N for “all except the oldest N”): stored in chrome.storage.local on your device until uninstall.

Not processed: conversation contents (messages), passwords, payment data, browsing history, data from other websites.

3. Recipients

Data is sent only to chatgpt.com (OpenAI), where the actions are performed; write requests happen only when you click. OpenAI’s privacy policy applies to their processing. No transfer to the developer or other third parties, no sale of data, no analytics, tracking or advertising, no remote code. The developer operates no servers for this extension and receives no personal data.

4. Permissions

chatgpt.com access – show the panel, read the conversation list, perform actions. storage – save the single setting N. scripting – inject the packaged panel into chatgpt.com tabs opened before installation.

5. Chrome Web Store Limited Use

The use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
